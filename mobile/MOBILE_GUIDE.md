# 📱 스마트폰(iOS / Android) 온디바이스 동작 가이드

스마트폰에서 **와이파이나 데이터 연결 없이(비행기 모드)** 중요한 문자, 카톡, 이메일을 감지하고 요약하기 위한 온디바이스 아키텍처와 구현 방법입니다.

---

## 1. 스마트폰 전용 초경량 추론 모델 (SLM) 선정

스마트폰은 RAM이 제한되어 있고(보통 6GB~12GB), 지속적인 배터리 소모를 방지해야 하므로 **4-bit 양자화된 0.5B ~ 1.5B 모델**이 가장 적합합니다:

1. **`Qwen2.5-0.5B-Instruct (int4 / GGUF)`**
   - **모델 크기**: 약 **350MB** (스마트폰 앱 내부에 번들로 탑재 가능)
   - **RAM 점유율**: ~500MB 미만
   - **추론 속도**: 최신 스마트폰 NPU/GPU 기준 초당 50~80 토큰 (알림 1개 요약에 **0.2초 소요**)
   - **한국어 이해도**: 카카오톡 구어체, 줄임말, 존댓말, 일정/금전 키워드 완벽 이해

2. **`Llama-3.2-1B-Instruct (int4)`**
   - **모델 크기**: 약 **700MB**
   - **RAM 점유율**: ~900MB
   - **추론 속도**: 초당 40~60 토큰

## 2. 스마트폰 OS별 알림 연동 방식

### 🤖 Android (갤럭시 등)
안드로이드는 OS 차원에서 외부 앱의 알림을 안전하게 읽을 수 있는 공식 API를 제공합니다:
- **`NotificationListenerService`**:
  - 카카오톡(`com.kakao.talk`), 기본 문자(SMS), Gmail 알림이 수신될 때 백그라운드에서 즉시 트리거.
- **추론 엔진**:
  - **`Google MediaPipe GenAI / LiteRT`** (NPU/GPU 가속)
  - 또는 **`llama.cpp Android NDK`**
- **동작 흐름**:
  ```
  [카톡/문자 수신] ➡️ NotificationListener 가로채기 
                ➡️ 온디바이스 SLM (0.2초 추론) 
                ➡️ [스팸/잡담]이면 자동 알림 취소(음소거)
                ➡️ [중요 알림]이면 알림 헤더에 '✨ 요약' 붙여 최상단 고정
  ```
- *구현 소스코드*: `mobile/android_notification_service.kt`

### 🍎 iOS (아이폰)
iOS는 보안상 타사 앱의 알림을 가로채는 권한이 제한되어 있으므로 다음과 같은 최적의 패턴을 사용합니다:
1. **단축어(Shortcuts) 자동화 연동**:
   - iOS '단축어' 앱의 자동화 탭에서 `[특정인에게 메시지가 올 때]` 또는 `[이메일 수신 시]` 트리거 등록
   - 온디바이스 앱 실행 액션으로 넘겨 백그라운드 요약 수행
2. **Apple Neural Engine(ANE) 가속**:
   - **`Core ML`** 또는 **`MLX Swift`**를 사용하여 배터리 소모를 최소화(거의 0에 수렴)하며 추론
- *구현 소스코드*: `mobile/ios_notification_service.swift`

## 3. 스마트폰에서 바로 테스트하기 (모바일 웹 뷰)

현재 개발된 서비스에 **스마트폰 전용 뷰**가 포함되어 있습니다:

```bash
# 1. 서비스 실행
python3 /Users/kangsikseo/local-intelligence/app.py
```

- 스마트폰(아이폰/갤럭시)에서 동일한 공유기 Wi-Fi에 연결하거나, Mac의 IP를 통해 접속:
  - 주소: `http://[Mac-IP주소]:8000/mobile`
- 스마트폰 화면에 꼭 맞는 **Apple Intelligence 스타일의 모바일 UI**에서 실시간 알림 요약과 중요도 필터링을 직접 확인할 수 있습니다.
- (브라우저의 "홈 화면에 추가"를 누르면 앱 아이콘으로 설치되어 비행기 모드에서도 PWA 형태로 작동합니다.)

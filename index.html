단순 텍스트 출력이 아닌, 입력된 사실(EDB)과 선언적 호른절(Horn Clause) 규칙을 바탕으로 새로운 사실(IDB)을 연역적으로 증명하는 Wirelog Datalog 엔진 명세입니다.

실행 중인 Wirelog Datalog 프로그램 (.dl)
// 1. 베이스 릴레이션 정의 (Extensional DB) .decl message(id: symbol, ch: symbol, sender: symbol, body: symbol) .decl entity_token(id: symbol, token: symbol, category: symbol, weight: number) .decl spam_token(id: symbol, token: symbol) .decl temporal_constraint(id: symbol, deadline: symbol) .decl action_required(id: symbol, action_verb: symbol) // 2. 차집합 연산: 스팸 및 광고 사실 추론 (Anti-join 배제용) is_spam(Id) :- spam_token(Id, _). // 3. 중요도/긴급도 복합 관계 조인 (Relational Join & Scoring) urgent_fact(Id, TotalScore) :- message(Id, _, _, _), TotalScore = sum W : { entity_token(Id, _, _, W) }, TotalScore >= 6. // 4. 스팸 부정(Negation) 필터를 거친 정제 사실 연역 curated_important(Id, Priority) :- urgent_fact(Id, Score), !is_spam(Id), Priority = (Score >= 14 ? "urgent" : "important"). // 5. 핵심 술어-목적어 트리플 결합에 의한 1줄 요약 사실 도출 one_line_summary(Id, Summary) :- curated_important(Id, _), message(Id, _, Sender, _), synthesize_predicate(Id, Sender, Summary).
